# Scientific Source Importer

Локальный плагин Obsidian для импорта научных источников по URL/PDF и из Zotero: скачивание PDF, извлечение метаданных, отображение карточки источника в правой панели и работа со ссылками.

## Статус

Основной развиваемый плагин для работы с научными источниками внутри Obsidian. Репозиторий вынесен отдельно от общего хранилища, чтобы код плагина развивался как самостоятельный проект.

## Установка

Папка плагина должна находиться в:

```text
.obsidian/plugins/scientific-source-importer
```

В текущем хранилище Obsidian эта папка подключена через junction-ссылку на отдельный репозиторий:

```text
S:/Users/HiDespondency/Documents/Obsidian Plugins/scientific-source-importer
```

## Состав

- `manifest.json` - описание плагина для Obsidian.
- `main.js` - основной код плагина и UI.
- `import-service.js` - импорт источников.
- `cyberleninka.js` - обработка CyberLeninka.
- `html-metadata.js` - извлечение HTML-метаданных.
- `pdf-metadata.js` - извлечение и сверка PDF-метаданных.
- `reference.js` - модель/форматирование источника.
- `zotero-importer.js` - импорт из Zotero.
- `zotero_import.ps1` - вспомогательный импорт из Zotero на Windows.
- `utils.js` - общие функции.
- `styles.css` - стили правой панели и элементов плагина.

## Примечание

Пользовательская база импортированных источников, кэш и локальные настройки не входят в публичный код плагина.

## Гарантии импорта

- Каждая новая запись сохраняется только вместе с локальным PDF в хранилище.
- Для каждой записи генерируется стабильный ключ `citationKey`, доступна Obsidian-сноска `[@ключ]` и локальная Obsidian-ссылка на PDF.
- ГОСТ-сноска строится из доступных библиографических полей; отсутствующие сведения помечаются для проверки и не выдумываются.
- Метаданные объединяются из Zotero, HTML, Crossref и текстового слоя PDF. Из PDF дополнительно извлекаются DOI, ISSN/eISSN, ISBN, УДК, LCCN, PMID/PMCID, arXiv, ГРНТИ, EDN, ключевые слова и явные библиографические поля.
- Для импорта из Zotero есть отдельный автономный режим дополнения импортированных источников: по DOI или названию он проверяет Crossref и официальную страницу, ищет PDF и скачивает его локально. Режим выключен по умолчанию и включается в настройках, поскольку отправляет библиографические данные во внешние сервисы; Zotero при этом не изменяется.
- Встроенная команда «Проверить импорт Zotero без записи» выполняет локальный dry-run: проверяет вложения и библиографические предупреждения, не изменяя хранилище и не выполняя сетевых запросов.
- Отсутствующий PDF только показывается в аудите. Записи о работах автоматически не удаляются; повторный импорт обновляет совпавшую запись, сохраняя ранее найденные непустые поля.

## Тесты
